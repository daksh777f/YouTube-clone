 🎬 YouTube Clone

### A Frontend Replica of YouTube Using HTML & CSS

---

## 📘 Overview
This project is a **frontend clone of YouTube**, built entirely using **HTML and CSS**.  
The goal of this project is to practice **web design, layout structuring, and responsive styling** while replicating the familiar interface of YouTube.  

This clone mimics key visual elements of YouTube, such as the **header, sidebar, video grid, and video cards**, but does **not include backend functionality or video streaming**.

---

## 🚀 Features
- 🖥️ **Homepage Layout** – Header, sidebar, and video feed similar to YouTube.  
- 🎨 **Responsive Design** – Layout adapts to different screen sizes.  
- 📺 **Video Cards** – Thumbnail, title, channel name, and view count displayed.  
- 🔍 **Search Bar** – Non-functional placeholder for search functionality.  
- ⚡ **Clean & Modern UI** – Styled with CSS for a polished, user-friendly look.  

---

## 🧩 Tech Stack
- **Frontend:** HTML5, CSS3  
- **Design:** Flexbox, CSS Grid, Hover Effects, Responsive Media Queries  

---

## ⚙️ How It Works
1. Open `index.html` in any modern web browser.  
2. The layout loads with a **header, sidebar, and main video grid**.  
3. Interactions like hover effects on video cards and navigation bar mimic YouTube’s feel.  
4. Fully **responsive** layout ensures usability on mobile and desktop.
